## Где ещё требуется работа команды

1. Встроить память и MCP-клиент в настоящий Agent Backend. Реальная цепочка MAX → ASR → LLM → пользователь → подтверждение ещё не проверялась; в наших тестах ASR и согласие вымышленные.
2. Обрабатывать сообщения одного пользователя последовательно и отсеивать повторную доставку MAX. Lua защищает операции Redis, но не целый многошаговый диалог.
3. Согласовать структуру Python-пакетов: сейчас наш каталог называется app, он может совпасть с app в backend. Это исходники для объединения, не опубликованная pip-библиотека.
4. Согласовать и проверить HTTP API: доверенный user_id, общая БД, авторизация и формат дат. Для изменения статусов нужны новые методы и миграция прав.
5. Реализовать отправку напоминаний по расписанию. Запись reminder только хранит событие; длительность встреч, повторения, задачи без времени и изменение/удаление не реализованы.
6. Перед публичным запуском: авторизация MCP/API, TLS/защищённая сеть, резервные копии и проверка восстановления. Сейчас порты только localhost, приложение не выдаётся за production-ready.
7. Разместить код в командном GitHub-репозитории и договориться об общем запуске. GitHub хранит код, не общую живую БД; отдельные копии не синхронизируют события.
